# ToolIsle 更新记录

## 0.2.0 — 2026-09-22

- 从此前未能恢复的暂存载荷改为独立、可构建的 Swift Package 应用入口；上游源码与版权记录保留，不加载原有后台服务。
- 使用维护者提供的 SVG，生成应用、开发版与菜单栏资源。
- 新增工具注册、搜索、分类、收藏、独立窗口及轻量灵动岛入口。
- 新增 JSON、时间戳和 Base64 工具。
- 新增 Gitee 令牌连接、Watch/Star 分页、按仓库的 Issue 状态/标题/标签筛选、正文、未读状态和评论阅读。
- 新增仓库分支/文件/README 浏览与本地 Markdown 阅读，支持相对资源解析与源码查看。
- 新增 Keychain、按账户隔离的可选离线缓存、退出后请求失效、限流与错误处理。
- 停用并归档上游自动化，固定依赖版本，提供只读 CI 权限、测试、macOS 编译、打包与无凭据启动检查。

当前为只读工具箱版本。私有账户联调、真实桌面交互、Developer ID 签名及 Apple 公证需在相应环境验收，不将模拟 API 测试等同于真实账号测试。
